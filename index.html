Research profile

Three ongoing research directions spanning 5G edge networks, industrial control systems, and smart manufacturing — unified by AI-driven, explainable intrusion detection.

Lightweight and Explainable AI-Based Intrusion Detection for Secure 5G Edge Networks

5G Security · Edge Computing · Artificial Intelligence · Intrusion Detection
ONGOING ⌄
Background

The increasing use of 5G networks, edge computing, network slicing, IoT, and virtualization has significantly expanded the cybersecurity attack surface. Existing research proposes AI-driven, multi-layered security frameworks incorporating federated learning, trust scoring, network-slice isolation, and deep-learning-based intrusion detection — though practical deployment is limited by edge-device computation, dynamic network conditions, and adversarial vulnerabilities.

Identified research gap
  • Computational and memory overhead at edge devices
  • Dependence on substantial training data
  • Vulnerability to adversarial manipulation
  • Challenges in real-time detection under dynamic network conditions
  • Practical deployment across heterogeneous environments
Problem statement

5G edge networks generate highly dynamic, heterogeneous traffic that challenges conventional and AI-based intrusion detection. There is a need for a lightweight, explainable AI-based IDS capable of real-time detection on resource-constrained edge environments while remaining resilient to adversarial behavior.

Proposed objectives
  • Reduce computational and memory requirements
  • Detect abnormal and malicious network behavior
  • Improve robustness against adversarial traffic
  • Provide interpretable explanations for detection decisions
  • Evaluate detection accuracy, latency, resource consumption and robustness
Expected contribution

A more practical AI-based security solution for 5G edge networks, bridging the gap between high detection performance and real-world edge deployment.

AI-Enabled Intrusion Detection and Automated Cyberattack Response for IEC 61850-Based Digital Substations

Industrial Cybersecurity · IEC 61850 · Digital Substations · AI · Intrusion Detection
ONGOING ⌄
Background

Digitalization of electrical substations using IEC 61850 and Industry 4.0 technologies turns conventional substations into complex cyber-physical systems. The reference study applies System-Theoretic Process Analysis (STPA) to identify unsafe control actions and hazards, then implements IEC 61850-based logical selectivity using GOOSE communication.

Identified research gap
  • No advanced intrusion detection mechanisms implemented
  • No quantitative cyber-risk assessment
  • No automated cyberattack response
  • STPA's qualitative nature limits scalability to large systems
Problem statement

IEC 61850 substations rely heavily on network communication for protection and control, making that infrastructure a critical target. STPA identifies cyber-related hazards but offers limited support for real-time detection and automated response — motivating an intelligent monitoring and response mechanism that assesses cyber risk and acts while preserving safety and reliability.

Proposed objectives
  • Monitor IEC 61850 network communication
  • Detect anomalous and malicious traffic using machine learning
  • Identify cyberattacks affecting protection communication
  • Assign a cyber-risk / threat-severity score
  • Initiate appropriate automated defensive responses
Expected contribution

Extends the existing STPA-based safety approach from hazard identification toward active cybersecurity detection and response — bridging safety analysis and real-time cyber defense.

Adaptive Cyberattack Detection in Smart Manufacturing Using Digital Twin Technology and Machine Learning

Smart Manufacturing · Digital Twins · Machine Learning · Cyber-Physical Security
ONGOING ⌄
Research gap

Current cyber-physical security solutions often monitor the physical or cyber system independently. Few approaches integrate Digital Twin technology with AI-based intrusion detection for continuous real-time monitoring and attack prediction.

Problem statement

Smart manufacturing increasingly adopts Digital Twins for monitoring and optimization, but existing security mechanisms rarely use them to detect attacks affecting cyber and physical components simultaneously — limiting early detection and prevention of physical damage.

Proposed research direction
  • Digital Twin technology
  • Machine learning
  • Real-time monitoring
  • Attack modeling
  • Cyber-physical defense
Expected contribution

Mechanical / Manufacturing — Digital Twin and manufacturing model. Computer Science — AI and Digital Twin implementation. Cybersecurity — attack modeling and defense.
